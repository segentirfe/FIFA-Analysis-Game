Goal of the FIFA Analysis Game:


To display FIFA 2019 information in a fun interactive way using dataset from FIFA 2019 dataset. It has 5 interactive buttons that display quiz, visualizations, and statistics on the players/clubs. It was my first time learning Object-Oriented Python so it has some bugs that I plan on troubleshooting.
