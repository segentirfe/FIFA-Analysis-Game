Goal of the FIFA Analysis Game:


To display FIFA 2019 information in a fun and interactive way using data from the FIFA 2019 dataset. It features five interactive buttons that display a quiz, visualizations, and statistics for players/clubs. It was my first time learning Object-Oriented Python, and this is the project I made with my team in INST 326.
